# دارویار (DaroYar)

**یادآور مصرف دارو برای اندروید** — سر هر نوبت، روی گوشی اعلان می‌آید.

رایگان، بدون تبلیغ، بدون نیاز به اینترنت. همهٔ اطلاعات فقط روی خود گوشی ذخیره می‌شود.

## امکانات

| بخش | توضیح |
|---|---|
| 🔔 اعلان سر وقت | برای هر نوبت اعلان می‌آید، حتی وقتی برنامه بسته است یا گوشی خاموش و روشن شده |
| ✓ «مصرف کردم» | از خود اعلان یا صفحهٔ «امروز» نوبت را ثبت کنید |
| ⏰ «۱۰ دقیقه بعد» | اگر الان نمی‌توانید، یادآوری ۱۰ دقیقهٔ بعد دوباره می‌آید |
| 📅 امروز | فهرست نوبت‌های امروز به ترتیب ساعت، با تاریخ شمسی، نوبت بعدی و نوبت‌های دیرشده |
| 💊 داروهای من | افزودن، ویرایش، حذف یا توقف موقت یادآوری هر دارو |
| ⚡ زمان‌بندی سریع | «روزی یک بار»، «هر ۱۲ ساعت»، «هر ۸ ساعت»، «هر ۶ ساعت» با یک لمس |
| 📦 موجودی دارو | با هر مصرف کم می‌شود و وقتی کمتر از ۳ روز مانده هشدار می‌دهد |

## ساخت APK

با هر push به شاخهٔ `main`، GitHub Actions تست‌ها را اجرا می‌کند و APK می‌سازد:
**Actions ← آخرین اجرا ← Artifacts ← `DaroYar-debug-apk`**

برای APK امضاشده (کافه‌بازار / مایکت) این Secretها را در **Settings ← Secrets and variables ← Actions** اضافه کنید:
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`

## نکته برای گوشی‌های شیائومی، هوآوی، سامسونگ و…

بعضی گوشی‌ها برای صرفه‌جویی باتری، یادآوری برنامه‌ها را متوقف می‌کنند. اگر اعلان دیر یا اصلاً نیامد:
**تنظیمات گوشی ← برنامه‌ها ← دارویار ← باتری ← «بدون محدودیت»** (و در شیائومی «Autostart» را روشن کنید).
با دکمهٔ 🔔 بالای صفحه می‌توانید یک اعلان آزمایشی بفرستید.

## فنی

- Kotlin + Jetpack Compose (Material 3)، حداقل اندروید ۸ (API 26)
- `AlarmManager.setExactAndAllowWhileIdle` با یک آلارم برای هر ساعتِ نوبت (همهٔ داروهای آن ساعت با هم اعلان می‌شوند)
- بازتنظیم آلارم‌ها پس از روشن شدن گوشی، به‌روزرسانی برنامه و تغییر ساعت/منطقهٔ زمانی
- فونت وزیرمتن، رابط کاربری راست‌به‌چپ، اعداد فارسی

⚠️ دارویار فقط یادآور است و جای توصیهٔ پزشک یا داروساز را نمی‌گیرد.
