# دارویار (DaroYar)

**یادآور مصرف دارو و مکمل برای اندروید** — سر هر نوبت، روی گوشی اعلان می‌آید.

رایگان، بدون تبلیغ، بدون نیاز به اینترنت. همهٔ اطلاعات فقط روی خود گوشی ذخیره می‌شود.

## امکانات

| بخش | توضیح |
|---|---|
| 🔔 اعلان سر وقت | برای هر نوبت اعلان می‌آید، حتی وقتی برنامه بسته است یا گوشی خاموش و روشن شده |
| ✓ «مصرف کردم» | از خود اعلان یا صفحهٔ «امروز» نوبت را ثبت کنید |
| ⏰ «۱۰ دقیقه بعد» | اگر الان نمی‌توانید، یادآوری ۱۰ دقیقهٔ بعد دوباره می‌آید |
| 📅 امروز | فهرست نوبت‌های امروز به ترتیب ساعت، با تاریخ شمسی، نوبت بعدی و نوبت‌های دیرشده |
| 💊 داروهای من | افزودن، ویرایش، حذف یا توقف موقت یادآوری هر دارو |
| ⚡ زمان‌بندی سریع | «روزی یک بار»، «هر ۱۲ ساعت»، «هر ۸ ساعت»، «هر ۶ ساعت» با یک لمس |
| 🗓️ روزهای مصرف | هر روز، «هفته‌ای یک بار» یا روزهای خاص هفته (برای متوترکسات، آلندرونات، ویتامین د ۵۰ هزار و…)؛ اگر داروی هفتگی مثل متوترکسات هر روز تنظیم شود، هشدار جدی می‌دهد |
| 📦 موجودی دارو | با هر مصرف کم می‌شود و وقتی کمتر از ۳ روزِ مصرف مانده هشدار می‌دهد |
| 🌿 مکمل و ویتامین | ویتامین‌ها (D، B12، C، E، A، K، ب کمپلکس، مولتی‌ویتامین)، مواد معدنی (آهن، کلسیم، منیزیم، روی) و مکمل‌هایی مثل امگا ۳، پروبیوتیک، ملاتونین و کوآنزیم کیو ۱۰؛ بهترین ساعت مصرف خودکار پیشنهاد و مثل داروها یادآوری می‌شود |
| ℹ️ اطلاعات دارو | با زدن روی هر دارو: برای چه مفید است، توضیح کوتاه، بهترین زمان مصرف و نکتهٔ مهم (بانک آفلاین ۱۵۳ دارو و مکمل رایج، با نام ژنریک و تجاری) |
| ⚠️ تداخل دارویی | بررسی خودکار تداخل بین همهٔ داروهای ثبت‌شده (۷۸ قانون، از جمله تداخل مکمل‌ها مثل ویتامین K با وارفارین، در سه سطح: جدی، احتیاط، فاصلهٔ زمانی) |
| 🕐 فاصلهٔ زمانی | برای داروهایی مثل لووتیروکسین و کلسیم، ساعت‌های واقعی شما را چک می‌کند و اگر فاصله کم است هشدار می‌دهد |
| ⏱️ ساعت پیشنهادی | برای داروهایی که زمان مصرفشان مهم است (مثلاً سیمواستاتین شب، امپرازول قبل از صبحانه) با یک لمس ساعت پیشنهادی را تنظیم کنید |

## ساخت APK

با هر push به شاخهٔ `main`، GitHub Actions تست‌ها را اجرا می‌کند و APK می‌سازد:
**Actions ← آخرین اجرا ← Artifacts ← `DaroYar-debug-apk`**

برای APK امضاشده (کافه‌بازار / مایکت) این Secretها را در **Settings ← Secrets and variables ← Actions** اضافه کنید:
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`

## نکته برای گوشی‌های شیائومی، هوآوی، سامسونگ و…

بعضی گوشی‌ها برای صرفه‌جویی باتری، یادآوری برنامه‌ها را متوقف می‌کنند. اگر اعلان دیر یا اصلاً نیامد:
**تنظیمات گوشی ← برنامه‌ها ← دارویار ← باتری ← «بدون محدودیت»** (و در شیائومی «Autostart» را روشن کنید).
با دکمهٔ 🔔 بالای صفحه می‌توانید یک اعلان آزمایشی بفرستید.

## فنی

- Kotlin + Jetpack Compose (Material 3)، حداقل اندروید ۸ (API 26)
- `AlarmManager.setExactAndAllowWhileIdle` با یک آلارم برای هر ساعتِ نوبت (همهٔ داروهای آن ساعت با هم اعلان می‌شوند)
- بازتنظیم آلارم‌ها پس از روشن شدن گوشی، به‌روزرسانی برنامه و تغییر ساعت/منطقهٔ زمانی
- فونت وزیرمتن، رابط کاربری راست‌به‌چپ، اعداد فارسی

- بانک دارو و قوانین تداخل در [`drugs/`](app/src/main/java/ir/daroyar/app/drugs) است؛ برای افزودن دارو یک `d(...)` به `DrugDatabase.kt` اضافه کنید (تست‌ها نام‌ها و برچسب‌ها را چک می‌کنند)

⚠️ دارویار فقط یادآور است و اطلاعات دارویی آن خلاصه و عمومی است؛ جای توصیهٔ پزشک یا داروساز را نمی‌گیرد.
